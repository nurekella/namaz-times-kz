# Namaz Times KZ

Время намаза для Казахстана по данным ДУМК ([muftyat.kz](https://muftyat.kz)) — виджет на рабочий стол и уведомления.
Қазақша · Русский · English.

## Возможности

- **Виджет**: часы, дата по григорианскому календарю и хиджре, отсчёт до следующего намаза, праздник дня.
  Перетаскивается мышью; размер — тянуть за правый нижний угол или Ctrl + колесо.
- **8 времён**: Тахаджуд, Фаджр, Восход, Духа, Зухр, Аср, Магриб, Иша — каждое можно скрыть.
- **Уведомления**: в момент намаза и заранее; колокольчик в строке виджета включает/выключает одним кликом.
  Джума — напоминание в пятницу до Зухра.
- **Аср**: Ханафи (как у ДУМК) или другие мазхабы.
- **Ручная поправка** каждого времени в минутах.
- **Расписание на месяц** с листанием по месяцам.
- **Исламские праздники** на год вперёд.
- **5700 населённых пунктов** Казахстана, список встроен и работает офлайн; поиск понимает «караганда» → «Қарағанды».
- Расписание скачивается раз в год и работает без интернета (`%AppData%\NamazTimes`).
- Проверка обновлений через GitHub Releases.

### Как считаются дополнительные времена

- **Тахаджуд** — начало последней трети ночи (Магриб → Фаджр).
- **Духа** — через 20 минут после восхода.
- **Аср не-ханафи** — время ДУМК минус астрономическая разница между тенью 2× и 1×.
- **Хиджра** — календарь Умм аль-Кура; в настройках есть поправка ±2 дня под объявления ДУМК.

## Скачать

Из [Releases](../../releases):
- `NamazTimes-x.y.z.msi` — установщик (меню «Пуск», удаление через «Приложения»);
- `NamazTimes.exe` — один файл без установки.

## Сборка

```
dotnet build -c Release
```

Установщик (WiX 5): `dotnet build installer -p:ProductVersion=0.2.0 -p:ExePath=..\out\NamazTimes.exe`

Релиз: `git tag v0.2.0 && git push --tags` — GitHub Actions соберёт exe и MSI и опубликует релиз.

Обновить список городов: `node tools/cities.mjs`.
