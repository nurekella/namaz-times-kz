# Namaz Times KZ

Время намаза для Казахстана по данным ДУМК ([muftyat.kz](https://muftyat.kz)) — виджет на рабочий стол и уведомления.
Қазақша · Русский · English.

![виджет](docs/screenshot.png)

- Виджет: перетаскивается мышью, правый клик — меню. Показать/скрыть — клик по значку в трее.
- Тахаджуд, Фаджр, Восход, Духа, Зухр, Аср, Магриб, Иша — каждый можно скрыть.
- Уведомления Windows в момент намаза и заранее (за N минут) — отдельно для каждого.
- Любой из ~5700 населённых пунктов Казахстана.
- Расписание скачивается один раз на год и работает офлайн (`%AppData%\NamazTimes`).
- Настройки: язык, город, уведомления, прозрачность, поверх окон, автозапуск.

Тахаджуд — начало последней трети ночи (Магриб → Фаджр). Духа — через 20 минут после восхода.

## Скачать

`NamazTimes.exe` из [Releases](../../releases) — один файл, установка не нужна.

## Сборка

```
dotnet build -c Release
```

Релиз: `git tag v0.1.0 && git push --tags` — GitHub Actions соберёт exe и опубликует релиз.
